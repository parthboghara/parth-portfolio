# Boghara Parth - Cybersecurity Portfolio

Professional portfolio website for **Boghara Parth**, Cyber Security Analyst and Aspiring Ethical Hacker.

## 📁 Portfolio Structure

```
portfolio/
├── index.html          # Home page with hero section
├── about.html          # About page with education
├── experience.html     # Work experience 
├── skills.html         # Technical skills & tools
├── projects.html       # Portfolio projects
├── contact.html        # Contact information
├── 404.html           # Custom 404 error page
├── style.css          # Complete stylesheet
├── script.js          # JavaScript for routing & animations
└── README.md          # This file
```

## ✨ Features

### Design
- **Dark cybersecurity theme** with animated starfield background
- **Glassmorphism effects** with backdrop blur on all cards
- **Cyan/teal accent colors** with glow effects
- **Animated geometric visualization** on home page
- **Smooth transitions** and hover effects throughout
- **Fully responsive** design for all devices

### Routing System
- **Multi-page architecture** with separate HTML files
- **Active page highlighting** in navigation
- **Keyboard shortcuts** for power users:
  - Arrow Right / N → Next page
  - Arrow Left / P → Previous page
  - Ctrl + Home → Home page
  - Ctrl + End → Contact page
- **Browser back/forward** support
- **Custom 404 page**

### Technical
- Pure HTML/CSS/JavaScript (no frameworks)
- Intersection Observer API for scroll animations
- Custom routing with active state tracking
- SEO-friendly with proper page titles
- Print-friendly styles

## 🚀 Getting Started

1. Download and extract the portfolio folder
2. Open `index.html` in any modern web browser
3. Navigate using the menu or keyboard shortcuts

**No build process or server required!**

```css
    --accent-cyan: #00ffff;
    /* ... */
}
```
